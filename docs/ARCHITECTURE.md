# Architecture

`apps/web` is the React/Vite operator UI. `apps/server` is the Fastify application and local SQLite persistence layer. `packages/shared` owns runtime contracts and task transitions. `packages/model-gateway` defines the provider-neutral model interface and mock adapter. `packages/agent-core` executes structured tasks. `packages/tool-runtime` contains workspace path and approval primitives.

The browser only calls the local API; privileged operations stay server-side. The gateway supports a deterministic mock adapter and OpenAI Responses, Anthropic Messages, Gemini `generateContent`, and Ollama `/api/chat` adapters. Responses normalize text, function calls, cancellation, and reported usage. Provider credentials are read from the server environment only; API responses never echo them. The agent runtime validates each model-requested tool against the task's registered tool list and runtime schema before execution, with a bounded step count. Only workspace-safe reads are currently exposed in the model loop. The current persistence implementation is a deliberately small `node:sqlite` adapter behind `DatabaseService`, allowing a future Drizzle migration without API churn.
