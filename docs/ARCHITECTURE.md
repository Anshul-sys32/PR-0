# Architecture

`apps/web` is the React/Vite operator UI. `apps/server` is the Fastify application and local SQLite persistence layer. `packages/shared` owns runtime contracts and task transitions. `packages/model-gateway` defines the provider-neutral model interface and mock adapter. `packages/agent-core` executes structured tasks. `packages/tool-runtime` contains workspace path and approval primitives.

The browser only calls the local API; privileged operations stay server-side. The gateway supports OpenAI Responses, Anthropic Messages, Gemini `generateContent`, local Ollama `/api/chat`, and an explicit deterministic Mock test adapter. The UI defaults to Ollama and probes its documented `/api/tags` endpoint to report daemon reachability and installed models; it never claims connectivity from registration alone. Responses normalize text, function calls, cancellation, and reported usage. Provider credentials are read from the server environment only; API responses never echo them. The agent runtime validates each model-requested tool against the task's registered tool list and runtime schema before execution, with a bounded step count. Model-loop filesystem access includes workspace-safe reads and approval-gated writes; public read-only browser/research helpers are not exposed as model tools, and no consumer AI website login automation is implemented. The current persistence implementation is a deliberately small `node:sqlite` adapter behind `DatabaseService`, allowing a future Drizzle migration without API churn.
